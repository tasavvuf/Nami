# Nami Frontend

React + Vite client for Nami, an anonymous note wall for feelings left unsent.

## Tech

- React 19
- React Router
- Vite
- Tailwind CSS
- Axios

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

The app expects the backend API on `http://localhost:5000`.

Nami keeps the interface soft on purpose: full-screen imagery, glass panels, emotional tags, and a quiet path from writing to letting go.
